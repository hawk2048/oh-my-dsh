# 报告证据与结构规范

`report-style.md` 管怎么说，本文档管**说了算不算数**。

---

## 一、证据表（正文之前必须存在）

`evidence.md`，一行一条：

```
S07 | 美国户储 2025 新增装机 12.4GWh，同比 +34% | bnef.com/xxx | A | 2026-01-15 | 高
S08 | 加州 NEM 3.0 余电收购价降至批发电价 | cpuc.ca.gov/xxx | A | 2023-11-02 | 高
S09 | 某券商测算美国户储 2026 增速 28% | 券商研报 | B | 2026-02-01 | 中
```

字段：编号 / 事实或数字 / 来源 / 级别 / 日期 / 置信度。

正文每个数字回指编号（`[S07]`）。回指不上的论断只有两条路：删掉，或降级成「有报道称……（待核实）」。

先写正文再补证据，一定会出现「这句很顺，但我不确定那个数字的口径」，然后这句就被留下了。

---

## 二、来源分级

| 级别 | 定义 | 能不能单独支撑关键结论 |
|---|---|---|
| **A** | 一手：官方披露、公告、财报、法律文本、原始数据库、代码/规范、可验证的经营痕迹 | 能 |
| **B** | 权威二手：署名研报、咨询报告、权威媒体原创调查、专家署名分析 | 能，但需说明分析方 |
| **C** | 弱线索：转载、榜单、未标口径的市占率/GMV/门店数、自媒体、社区讨论 | 不能；只能证明「有人这样说过」 |
| **D** | 不可用：聚合页、SEO 内容、无署名洗稿、AI 生成内容 | 只能用来找线索 |

三条硬规矩：

1. **去重**：多篇转载同一原始报道，算一个来源。
2. **家族去重**：同一来源体系的多条信号只算一个独立来源（官网 + 官方公众号 + 官方 App 算一家）。
3. **时效**：超过 180 天的数据按历史参考，不单独支撑「当前状态」判断；必须用时标时滞。

## 三、主张-证据矩阵

把关键结论拆成可核查主张，每条两边对齐：主张 → 证据编号。

| 缺口类型 | 标注写法 |
|---|---|
| 只有一个来源 | `单一来源` |
| 来源存在但未交叉 | `未充分交叉验证` |
| 两个来源打架 | `来源冲突：A 说 X（S03），B 说 Y（S05）` |
| 找不到一手 | `截至访问日未找到一手来源` |

**承重引用要开页核对**：TL;DR 里 3–4 条决策级结论，逐条打开来源页确认「内容确实支撑这句话」，不能只看链接能打开。行业里最常见的引用错误在「链接有效但内容不支撑」这一档，链接失效反倒少见。

**决策级结论由 C 级来源单独支撑** → 直接降级，或删。带脚注的谣言仍然是谣言。

## 四、反证（这是报告与资料汇编的分界线）

写完结论，专门写一段「它可能错在哪」：

1. 列出所有可能的替代解释（还有哪些原因能解释这个现象）。
2. 说明各自怎么排除的（控制了什么变量、交叉了哪个数据）。
3. **诚实说出没排除掉的。**
4. 主动降级结论（「这是早期描述性指标，不是因果估计」）。

第 3、4 步最容易跳过，也最值钱：你主动认领局限，读的人才不用替你找。

**找不到反证数据时怎么写**：

> 我们尝试查找 X 方面的反证（关键词……，来源范围……），未找到可用数据。因此这条结论的置信度下调为中等，需后续验证。

不许为了凑反方而编造风险，也不许把「数据缺失」写成「已被证伪」。

---

## 五、结构骨架（标准六章，缺章即不合格）

1. **核心结论**（TL;DR）：3–5 条，每条一句，带数字。
2. **对比总表**：一张能独立读懂的表，标「数据截点」。
3. **逐项详析**：一节一个主张，首句是判断句。
4. **冲突与存疑**：来源打架的地方，给最可能解释 + 下一步验证动作。
5. **未覆盖与限制**：没查的、查不到的、口径不一致的。
6. **来源清单**：S 编号 + 标题 + 发布方 + 日期 + URL。

brief 档可合并 3 与 4；comprehensive 档把 3 拆成多章。缺第 1、4、5、6 章一律不算完成。

## 六、篇幅与图表

**权威表在 `SKILL.md` 第 0 步**（brief 600–1500 / standard 2000–5600 / comprehensive 6400–14400，总字数 = 小节数 × 每节字数）。两份文件出现分歧时以 SKILL.md 为准。

- 附录 ≤ 正文 10%，附录是来源表，一条来源一行，不印数据表。
- 图表标题写结论，不写主题：`按职能划分的招聘计划` ✗ → `研发与销售扩张，客服与 G&A 收缩` ✓（研报型例外，查数的人要中性索引）。
- 图表下必须有数据源行：`来源：BNEF 2026.1 ｜ 制图：本文`，区分谁采的数、谁做的图。
- 百分比一律带分母：`7%（951 家企业，Bain 2026）`。
- 单段 ≤7 行（约 300 字），超了拆段。

---

## 七、结论要分层

- **我们发现**：跟着数据走，可复核。
- **我们认为**：跟着判断走，标出这是我的判断。

两样混在一起写，整段可信度按最弱的那句算。

- [ ] 冲突写进「冲突与存疑」，没拿「综合判断」蒙过去。
- [ ] 局限单独成节。
- [ ] 附录 ≤10%，是来源表不是数据表。
- [ ] 六章齐全（或按档位合并后齐全）。

- [ ] 逐句自问过一遍：删掉这句，读者对结论的判断会变吗？不变就删。
