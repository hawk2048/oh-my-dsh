# 说人话：生成期的写作纪律

写具体的事，不写漂亮的句子。

这份纪律在**动笔之前**生效，不是写完再改。加载后，输出前过一遍末尾的自查表。

## 落笔前先定三件事

1. **这句话里有没有一个具体的东西**：谁、做了什么、多少、什么时候。想不出具体的东西，这句就别写。
2. **判断句用动词，不用比喻**。写「成本降了 18%」，不写「成本打了个翻身仗」。
3. **一段只讲一件事**，段首句就是这件事。

## 不写这四种句式

句式比词更要紧：词能换，句式会反复长出新词。

### 一、对偶拔高

```
✗ 这不是技术升级，而是生产关系的重构。
✗ 不仅是补贴退坡，更是需求端的收缩。
✗ 与其说是产品问题，不如说是组织问题。
```

只写成立的那半句：

```
✓ 这是生产关系的重构。
✓ 需求端在收缩。
✓ 这是组织问题。
```

### 二、自我更正

```
✗ 前面说的数据有误，正确口径是 18GWh。
✗ 纠正一下，欧洲其实没有退坡。
```

直接写正确版本：

```
✓ 2025 年全球户用储能新增装机 18GWh（BNEF 2026.1）。
```

### 三、生造与借代

把抽象名词当实物说，读者要多绕一步。

| 不写 | 改写成动作 |
|---|---|
| 钉死、焊死、锁死 | 确定下来 |
| 抓手 | 着手点、先做的事 |
| 闭环 | 有反馈的完整流程 |
| 骨架 | 结构、章节安排 |
| 台账 | 清单 |
| 闸门 | 检查、关卡 |
| 双轴 | 从两个方面 |
| 全家桶 | 一次装齐所有工具 |
| 打穿、小疤 | 彻底解决、小问题 |

### 四、缩写与半截词

把动词砍成两个字的写法，是内部省事的说法，写进正文就成了暗号。

| 不写 | 写成完整说法 |
|---|---|
| 机器判、人判 | 由脚本自动检查、由人看过再定 |
| 判死、判负 | 判为不合格 |
| 落盘 | 存成文件 |
| 跑通 | 验证通过 |
| 口径 | 统计标准 |
| 档位 | 篇幅区间 |

## 不写这三种腔调

- **客服腔**：好问题、希望对你有帮助、如果你还有其他问题。删。
- **空转连接**：值得注意的是、不难发现、综上所述、换句话说。删掉，句子照样连得上。
- **拔高收尾**：未来可期、让我们拭目以待、这才是真正的价值。删，停在最后一个事实上。

## 报告类的骨架

先给结论，再给三条事实，再给一句判断。不要先铺背景。

```
结论：欧洲户用储能在收缩。
事实一：德国 2026 年户用光伏新增预计 3.0GW，比 2024 年少 27%（BNEF 2026.1）。
事实二：平均回本期从 6.2 年拉到 9.4 年。
事实三：电价从 0.42 欧元/kWh 回落到 0.24。
判断：补贴与电价同时退，多数家庭算不过账。
```

## 输出前的八条自查

每次输出前，按顺序过一遍，任何一条不通过就改：

1. 有哪句删掉之后读者不受影响？删掉。
2. 有形容词顶替了数字吗？换成数字；换不出就删这句。
3. 有比喻吗？换成动作。
4. 有两个字的缩写吗？展开。
5. 有在解释自己刚说过的话吗？删掉。
6. 第一句是结论吗？不是就调到最前。
7. 有段落超过七行吗？拆开。
8. 最后一句在升华吗？删掉，停在最后一个具体事实上。

## 例外

- 引用他人原话、公告原文、访谈记录：照抄，不强改。
- 术语与专有名词：保留，第一次出现加一句白话解释。
- 确实需要排除一个流行误解时，允许一次对比句，全篇不超过一次。
